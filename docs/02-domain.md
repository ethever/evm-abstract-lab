# 02：让一份状态代表许多执行

本课目标：理解抽象值、join、Top、偏序，以及它们为什么能帮助分析循环和跳转。

## 从分支后的一个栈槽位开始

设程序根据 calldata 走两条路径，一条把 1 压栈，另一条把 2 压栈，然后在 pc=14 汇合。我们不枚举所有 calldata，而保存：

```text
左路：slot0 = {1}
右路：slot0 = {2}
汇合：slot0 = {1,2}
随后 PUSH 10、ADD：slot0 = {11,12}
```

运行 `explain --file examples/diamond.hex`，对照输出中的入栈与出栈。这是一个非常小的抽象解释器：指令在“可能值的摘要”上执行。

## 一个槽位的抽象域

[`Value`](../crates/evm-abstract/src/domain.rs) 是非空有限集合或 `Top`（输出为 `⊤`）。默认最多保留 8 个常量。

| 抽象值 | 它代表的具体值 | 信息精度 |
| --- | --- | --- |
| `{7}` | 只能是 7 | 精确 |
| `{7,9}` | 7 或 9 | 较粗 |
| `⊤` | 任意 256 bit 值 | 最粗，但覆盖全部可能 |
| `⊥` | 没有执行到这里 | 由工作表里缺少状态表示 |

`Value` 的内部字段私有，避免把空集合放进一个“可达”栈槽位。可达性属于状态层，值的信息属于槽位层。

## join 为什么取并集

用 `a ⊑ b` 表示 b 至少覆盖 a 的全部具体值。`{7} ⊑ {7,9} ⊑ ⊤`。注意“更大”意味着覆盖更多、信息更少。

`a ⊔ b`（join）是同时覆盖二者的最精确可表达摘要：

```text
{7} ⊔ {9} = {7,9}
{7,9} ⊔ {9} = {7,9}
{7} ⊔ ⊤ = ⊤
```

容量为 1 时，`{7} ⊔ {9}` 只能是 Top。若为了保持容量只留下 7，就漏掉了具体执行中可能出现的 9。那是错误地删除行为。

这个 join 满足交换律、结合律、幂等律。[性质测试](../crates/evm-abstract/tests/domain.rs) 用随机集合检验它们，工作表的正确性依赖这些规律。

## transfer 如何覆盖具体操作

对于两个有限集合，ADD 计算笛卡尔积上的所有和。例如 `{1,2} + {10,20}` 得到 `{11,12,21,22}`；超过容量则返回 Top。输入中有 Top 时，通常输出 Top；比较运算的结果即使未知也只可能是 0 或 1。

EVM 数字是 U256，ADD/MUL/SUB 按模 2²⁵⁶ 运算。DIV 除零返回零；SHL/SHR 位移 ≥256 返回零；有符号运算使用二进制补码。大整数、模乘、快速幂使用 alloy/ruint。`Domain::apply` 只连接这些操作与 EVM 语义，不重写大整数库。

Osaka 加入 `CLZ`（count leading zeros）：U256 的最高位为 1 时结果为 0，只有最低位为 1 时为 255，全部为零时为 256。实现直接调用 alloy/ruint 的 `leading_zeros()`。未知输入的结果范围是 0..=256；有限集合容量放不下时仍返回 Top，不能只保留几个结果。指令是否启用由选定 fork 检查，抽象域只计算数值语义。

参数按**栈顶先弹出**的顺序：SUB(a,b)=a-b。字节码 `6002600303` 先压 2，再压 3，结果是 3-2=1。比较与移位也要按规范核对，不能把源码习惯的顺序直接搬过来。

[revm 对照测试](../crates/evm-abstract/tests/concrete.rs) 使用另一个执行器核对全部已支持纯操作的边界样本与随机 256 bit 输入。

## 关系丢失发生在哪里

两条具体路径的栈分别是 `[1,10]` 和 `[2,20]`。逐槽 join 得到 `[{1,2},{10,20}]`。这个乘积还包含 `[1,20]` 和 `[2,10]`，虽然原程序没有这些组合。

保守性保住了真实行为，精度却降低了。这叫**非关系域**：没有记录两个槽位之间的配对关系。路径划分、关系域或约束求解可以提高精度，但会增加成本。第五课会把这些不同选择放在一起比较。

## 循环为什么能收敛

一个槽位沿着循环可能逐步成为 `{0}`、`{0,1}`、……，超过容量升到 Top，然后不再变大。在固定容量域中，严格上升链长度有限。栈高最多 1024，上下文长度有界，程序块数有限，因此结构状态空间也有限。

数学上的终止并不意味着实际很快：状态空间可能很大。因此仍需要预算，并显式报告 `Incomplete`。

一般的区间域，例如 `[0,0] → [0,1] → [0,2] → ...`，可能需要 widening 加速到 `[0,+∞]`。本仓库用有限高度域，直接 join 就能收敛；不把容量截断假装成已经实现了通用区间 widening/narrowing。
