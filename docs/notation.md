# 统一显示符号

浏览器、CLI 文本、DOT 的可见标签和教程使用同一套身份记号。下标表示原始数字 ID：`σ₁₂₈` 仍指状态 128，不是第 128 次执行，也不是账户编号。SSA 值继续写作 `%0`、`%1`。

| 记号 | 身份与范围 |
| --- | --- |
| `σᵢ` | 原生机器状态；浏览器各视图和世界／RPC 报告共用这个编号 |
| `σᵖᵢ` | 单程序 CLI 投影状态；上标 p 表示 projection，与原生状态属于不同编号空间 |
| `Pᵢ` | 浏览器报告中捕获的程序，按代码地址、hash 和执行模式区分 |
| `Bᵢ` | 某个程序内的基本块；不同程序可以各有 `B₀` |
| `eᵢ` / `Tᵢ` | CFG 原生边／SSA 转移；按各自报告的原始边或转移 ID 阅读 |
| `fᵢ` | 某个状态中的调用帧，从外到内编号；`f₀` 是根帧 |
| `μᵢ` | 粗粒度整机效果的 SSA 名字，连接 memory、账户 Store、回滚点等依赖 |
| `Oᵢ` / `Uᵢ` | 入口结果／尚未展开的分析前沿 |
| `Cᵢ` / `Aᵢ` / `Hᵢ` | 文本报告中的代码／账户地址／hash 引用；完整身份保留在对应目录中 |
| `storeᵢ` / `bytesᵢ` / `Lᵢ` | 报告中的 Store 快照／字节数组快照／日志 |
| `summaryᵢ` / `certᵢ` | 调用摘要／摘要证书；证书与代码目录 `Cᵢ` 分开命名 |
| `exprᵢ` / `freshᵢ` / `scopeᵢ` | 报告中的符号表达式／新鲜符号身份／输入或分析的身份范围 |
| `taskᵢ` | 后端分析任务；取消、状态查询和报告关联沿用原始任务 ID |

例如 `μ₄ → μ₁₇` 表示效果依赖从 4 传递到 17，不表示已经计算了这两个效果之间的状态差异。`%0 = φ(σᵖ₁: %4, σᵖ₂: %5)` 按局部前驱选择值；跨合约 φ 则保留 `Tᵢ` 来源和 `fᵢ` 栈槽，不能直接替换编号空间。

单程序部分 SSA 中的 `Single-program state mapping` 明确给出 `σᵖᵢ → σⱼ` 的对应关系。JSON 的 `local_state` 和 `machine_state` 仍是整数；两个字段的数值偶然相同，也不能证明它们属于同一身份。

## 浏览器排版与搜索

egui 将符号和数字排成同一段文本，下标数字使用较小字号并向下对齐，投影标记 `ᵖ` 使用小字号上标；字号、颜色和粗细继承所在控件的样式。布局文本保留完整的 Unicode 符号，因此控件辅助阅读、复制和文本导出使用相同的 `σ₁₂₈` 记号。

字体随 Wasm 打包。小型派生字体补齐下标数字和 `ᵖ`，排版时选择与正文相同来源的数字／p 字形，避免上标缺字或下标回退到另一种字体。字符本身不替换成 ASCII；数字仍通过 egui 的字号与位置排成上下标。符号由 egui 查找字形，不依赖浏览器 CSS 字体，也不需要运行 LaTeX 引擎。可见文本不会显示 `\sigma_128` 这样的命令字符串。

实例搜索接受原始整数 `128`、`σ₁₂₈`、`σ128`、`sigma_128`、`\sigma_{128}`，并保留旧输入 `S128`。这些写法都查找原生状态 128；搜索不接受 `σᵖ₁₂₈` 隐式切换到局部编号空间。搜索后的 CFG、SSA 和检查器仍通过整数 ID 联动。

多实例基本块总览卡片显示 `P₀:B₀ · 129 states` 这样的程序／块标题。它不是新状态，不会把整张卡片命名为某个 `σᵢ`；选择具体实例后才显示它的原生状态、SSA 和快照。

## 数据与导出

共享的 [`evm-abstract-notation`](../crates/evm-abstract-notation) 负责身份格式与状态搜索解析；[`notation.rs`](../crates/evm-abstract-web/src/notation.rs) 负责 egui 下标排版。CLI 文本、DOT 可见标签和辅助阅读文本使用 Unicode 下标，例如 `σ₁₂₈`、`μ₁₇`。

JSON 字段名、整数 ID、Rust 类型和 DOT 结构标识仍按机器接口读取。pc、字节、数值常量、跳转历史和 `%` 值名保持各自的表示方式，不因为身份使用下标而改变含义。教程中的合约昵称 A、B、代理 P1/P2 也不是报告身份编号。

表达式、新鲜身份、范围和任务 ID 保持 64 位整数；在 32 位 Wasm 上显示下标时也不会截断或通过浮点数舍入。
