# Model-to-production contract

The checked target in each row is the displayed mathematical operation. The
Rust symbols identify the production mechanism that must implement it; they
are a manually reviewed correspondence, not extracted Rust semantics. The
richer numeric domain, source identities and complete EVM executor remain
explicit obligations below.

The [proof checker](../../proofs/check.sh) checks 188 public theorem and
regression targets, audits their dependencies, and requires the false old-join
claim to be rejected. See [README.md](README.md) for the pinned checker and
trusted infrastructure. Rust regressions provide separate executable evidence;
they do not discharge a universal Rust-to-model simulation theorem.

The formal target is each displayed model operation. Binding a row requires
reviewing the final Rust function, preserving the listed regression's semantic
expectation, and recording its actual outcome on the frozen integration head.
Passing all rows still does not imply a theorem of the entire Rust EVM.

## Reproduce the checks

The focused Rust groups below exercise the listed production boundaries without
claiming that every allowed execution has been enumerated:

```sh
nix build --no-update-lock-file --no-link .#checks.x86_64-linux.lean-proofs
nix develop --no-update-lock-file --command cargo test --offline --locked \
  -p evm-abstract --test world_join_facts --test eip161 --test log_sources \
  --test known_recursion --test unknown_world
nix develop --no-update-lock-file --command cargo test --offline --locked \
  -p evm-abstract --lib world::bytes::tests::scoped
nix develop --no-update-lock-file --command cargo test --offline --locked \
  -p evm-abstract --lib conditional_normalization
nix develop --no-update-lock-file --command cargo test --offline --locked \
  -p evm-abstract --lib analysis::layers::tests
```

Record source identity and actual exits separately when executing these commands.
A successful model check or a focused Rust group is not a completed repository
gate, and neither is a proof of every EVM opcode or abstract-domain operation.
