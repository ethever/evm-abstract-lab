# Model-to-production contract

The formal target in each row is the displayed mathematical operation. The
Rust symbols identify the production mechanism that must implement it; they
are a manually reviewed correspondence, not extracted Rust semantics. The
richer numeric domain, source identities and complete EVM executor remain
explicit obligations below.

The [proof checker](../../proofs/check.sh) checks public theorem and
regression targets, audits their dependencies, and requires the false old-join
claim to be rejected. See [README.md](README.md) for the pinned checker and
trusted infrastructure. Rust regressions provide separate executable evidence;
they do not discharge a universal Rust-to-model simulation theorem.

The root-model rows below bind public proof source
`2c0181de2a9da64818b4eaf1b490f0594102e71b` to Rust source inspected at integrated
`e5f13b82c16798431ad0bf7cbb7cfdb7ef3dc2f3`. Their named Rust regressions are
source bindings, not execution results from this documentation update. The
actual 296-target public Nix checker result is recorded in
[README.md](README.md#checker-and-evidence); final native/browser and repository
gate evidence remain separate.
