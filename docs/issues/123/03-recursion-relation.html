03 · 自然数上的递归

逐层返回，也可以用关系描述

f(3, 10) 调用到 f(0, 13)，返回值沿每一层保持为 13。

f(d, x):
    if d == 0: return x
    else:
        return f(d - 1, x + 1)
教学数域：d, x ∈ ℕ

d 每次减 1，最终到 0。

关系摘要：r = x + d

向下调用：d − 1，x + 1

向上返回：结果保持为 13

f(3, 10)
return 13
↓
↑
f(2, 11)
return 13
↓
↑
f(1, 12)
return 13
↓
↑
f(0, 13)
→
return 13

Base：d = 0，直接返回 x = 13。

用 base / step 说明本例的摘要

Base · d = 0

r = x = x + 0

Step · d > 0

若子调用满足摘要，父调用返回同一个 r：

r = (x + 1) + (d − 1) = x + d

f(3, 10) ⇒ r = 10 + 3 = 13

教学示例。本例在自然数上成立；这不是对任意 EVM 递归的证明，
也不代表当前引擎已完整实现关系式递归摘要。
