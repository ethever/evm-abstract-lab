01 · 自然数上的循环

循环没停，分析可以收敛

用一个覆盖后续状态的区间，替代不断增长的有限上界。

x = 0
while true:
    x = x + 1
教学数域：x ∈ ℕ

这里用自然数，不考虑机器字回绕。
循环每次把 x 增加 1。

初始 I₀

[0, 0]

只有 x = 0

→

第 1 次 join · I₁

[0, 1]

加入下一步的 1

→

第 2 次 join · I₂

[0, 2]

上界继续增加

→

widening

[0, +∞)

覆盖之后的增长

下一轮 join 将得到 [0, 3]I₂ ▽ [0, 3] = [0, +∞)

▽ 表示 widening：把从 2 继续增长到 3 的上界推广为 +∞。

再执行一次 x + 1，结果仍被覆盖

image(x + 1, [0, +∞)) = [1, +∞)

[1, +∞) ⊆ [0, +∞)

入口 0 和后续状态都在区间内，分析结果可以保持不变。

分析收敛：抽象结果不再需要扩大。

程序行为：while true 仍继续执行。

教学示意。+∞ 表示没有有限上界，不是运行时值；
本图的 widening 时机和自然数域仅用于教学。
